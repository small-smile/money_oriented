股权结构页

【总体目标】
  板块之间只差顶部那条导航，正文、图、表完全一样
- 页面上只有一条导航（全局导航条）：板块由后端按 ?code= 判定，
  ?code=600941 单参数即可；公司切换补进同一条导航（银行用 header 自带的 45 家面板）
- 数据层有多少就画多少图：缺哪一层就少哪张图、少哪段话，不为板块写分支
- 每张图下那段解读由接口按本公司自己的序列现算（narrative.<图 id>），不写死在 HTML 里
- **数据源不单独占一节**：出处拆到每个 section 自己身上 —— 卡片右上角一行小字
  「<出处> ｜ <口径>」，按口径着色，只标不点（完整出处在图下「展开详细口径」里）。
  看某张图的人不必回页首去找它的数是哪来的。
  现状（2026-09-17 已推广）：所有图与所有公司都挂来源标签，出处/口径由 /api/holders 的
  company.sources[图 id]{tier,label,from} 下发（shareholder.js 的 srcTag → attachSourceTag +
  shareholder.css 的 .src-tag），不再只有 600941
- 口径（标签后半句）说的是**这个指标现在从哪一层取的数**，不是年份区间：
  年报原文是目标口径，第三方接口（东方财富）只是省事的临时口径，标签虚线边＋「待升级年报」
  同时充当待办清单 —— 页面上哪些指标还欠一次年报抽取，扫一眼标签就知道

一、页面骨架（自上而下）
────────────────────────────────────────
- 页头：公司名（证券代码）· 股权结构；副标题印两地代码
- 历年每 10 股分红（整页第一张图，插在环形图之前）
- 股东结构环形图（双层 + 口径切换按钮 + 图下分组依据说明）
- 其余图表（#charts，顺序见第四节）


────────────────────────────────────────
二、每个 section 的数据源标签
────────────────────────────────────────
标签就在 section（.chart-card）**右上角**，与图标题同一行的右端 —— 一行小字，
**只是标识：不可点、不弹层**（弹层会压住图或下一节，且与图下的口径说明重复）。
标签内容 = <出处> ｜ <口径>，尽量短：
- **口径 = 这个指标现在从哪一层取的数**，只有三档（shareholder.js 的 SRC_TIER）：
  annual 年报口径（绿、实线，交易所年报原文，这是目标口径）
  api    第三方口径 · 待升级年报（蓝、**虚线**，东方财富接口取的数）
  manual 手工口径（琥珀、实线，本地抽取件，不是交易所原文）
  kind 认不出来的一律降到 api 档 —— 没标明出处的指标默认按「还没升级」处理
- 虚线那档同时是待办：接口取数是当下为省事／省 token 的临时选择，最终都要换成年报原文；
  换完把 kind 改成 annual，虚线自动变实线，不用另记一份清单
- **口径不是年份区间**：图覆盖到哪些年份 x 轴自己说明，标签不重复
- 完整出处（history_source / holders_caliber 那些整段文字）仍在图下那段「展开详细口径」里，
  标签只给一句话的来源名，不重复长文
按图取对应来源：
- 分红、股本这类历年序列 → company.history_source 归纳成「A 股年报（上交所）」这类短名，
  是逐年通读年报抄的就走 annual
- 环形图与「股东明细」弹框 → 名册出处（年报名册 / 东财接口快照 / 20-F）；
  接口快照那份走 api 虚线档
- 手工抽取层的公司走 manual 琥珀档，标明是本地抽取件而不是交易所原文


────────────────────────────────────────
三、环形图（这一页的主图）
────────────────────────────────────────
- 内圈一名股东一块、外圈按分组归并；**圈序固定，不设两圈互换按钮**
  （互换后读法不变，只是把同一张图翻个面）
- 数据层给了附加口径（渝农商行 H 股年报两张）时，图上按钮切口径，
  切过去连口径说明一起换
- 合计不足 100% 的部分补成「其他股东（前十名之外）」，挂在图左边
- 版面（行高、字号、列宽、半径、画布高度）全部按数据量与实测文字宽度算，不写死
- 点右侧标注行出全称；点「股东明细」出全量长名清单弹框（带所属分组与色块）——
  页面上那张明细表撤掉后，逐个股东的持股数、增减、类别只在这个弹框里看
- 图下说明必须写清「同类归并不是年报披露的一致行动人」，并逐组列出归类依据


────────────────────────────────────────
四、图表清单与顺序（数据层缺就少画）
────────────────────────────────────────
1. 历年每 10 股分红 —— 银行原先那页的红柱：柱身与柱顶标签同为 #c0392b，
   y 轴从 0 起，barMaxWidth 44；年份 > 16 个只收字号不隐藏标签。
   港元宣派的公司（中国移动）照港元画，不做汇率换算
2. 前十名股东持股比例 —— 横条，按股份类别着色（A 股／H 股／限售，百度按 A 类／B 类）
3. 持股集中度 —— 一条 100% 横条：第一大股东／第 2—10 名／名册外其余股份
4. 股东户数（逐披露期）—— 总数 + A/H 拆分，拆分缺的期次留空断线，不插值
5. 持股集中度（逐披露期）—— top1/top3/top10，另有剔代理人两条与投票权那条，
   有哪条画哪条，说明文字跟着实际画出来的线走
6. 历年总股本变动 —— 银行原先那页的阶梯折线：step: 'end'、#6c3483 紫线 +
   8% 紫色面积、末点标当年股本、点上只标当年增量（≥ 上年股本 0.1% 才标），
   y 轴从 0 起。点色：数据层给了资本运作类型就按银行调色板（IPO 红 #c0392b /
   定增 橙 #e67e22 / 增发·绿鞋 青 #16a085，平年灰 #95a5a6）；
   没有类型层就降一阶，只分「动过（紫）／未动过（灰）」，不按原文措辞猜类型
- 拆股／并股的口径断点（百度 1 拆 80）：竖虚线标出，断点左侧各年折算到断点后口径，
  tooltip 同时给年报原文股数；断点那一年不算「当年增量」
- 一律不加 dataZoom


────────────────────────────────────────
五、数据契约（/api/holders 给什么，页面吃什么）
────────────────────────────────────────
页面不认公司、不认板块，只认字段：**给了哪层就画哪张图，缺了就少一张**，
所以新增公司只补数据层就够（数据层怎么抽、字段怎么填见 prompt/add-company.prompt.txt）。
（后端 2026-09-17：/api/holders 优先读合并表 data/tables/<板块>_<code>_shareholder.json —— 由
data/extract/build_shareholder_tables.py 把 annual/company_charts/holders_manual 三处合并、
另带 sources 出处块；无表则退回 read_holders 的 _stitch_rec 现拼，两条路数据逐字一致。下面字段契约不变。）

顶层：{code: 200, data: {industry, label, roster[], company{}}}
- industry / label   板块 id 与中文名（配色、页头那行、板块统一口径都取它）
- roster[]           本板块名单 [{code, name, tag, has_holders}] —— 导航里的公司切换；
                     has_holders=false 的置灰（纯 H 股接口不返回名册）

company 里每个字段对应页面上的一处，**没有就不画**：
- name / secucode / tag / codes{a,h,us,same_entity,...} / code_note   页头两行
- source / holders_caliber / holders_end_date                         名册出处与报告期
- holders[{rank,name,hold_num,ratio,change,state,shares_type,total_shares,pledged}]
                     环形图内圈与「股东明细」弹框；ratio 的分母是 total_shares（总股本）
- factions[{title,color,names,basis}]                                 环形图外圈；缺则只有单层环
- ring{caliber,holderData,factions} / ring_alt[] / ring_label          年报口径那份环形图与口径切换按钮
- residual_label / caliber_note / factions_source                     环形图残余块叫法与图下说明
- dividend_per10 [[年, 每 10 股]] + dividend_unit                      图①（新增公司还要给
                                                                      dividend_total，见 add-company）
- holder_num [[日期, 总户数, A 股户数, H 股户数]]                        图④（拆分为 null 就断线，不插值）
- holder_concentration [{date,top1,top3,top10,top1_name,top1_ex,...}]  图③与图⑤（有哪条画哪条）
- share_capital [[年, 股数, 变动原因, 资本运作类型]] + share_capital_break{at,factor,text}
                     图⑥；第 4 位是类型（ipo/pp/seo…），没有就降阶成「动过／未动过」两色
- narrative.<图 id>{text, detail}                                     各图下那段现算解读
                     （图 id：divper10 / holders / concseries / holdernum / sharecap）
- history_source / history_gaps                                       出处与缺口（**页面已不印**，
                     留着给来源标签与排查用）
- sources.<图 id>{tier, label, from}                                  每张图右上角来源标签用
                     （tier: annual 年报／api 第三方／manual 手工；图 id 同 narrative + ring/holders）

改后端字段名或加一层数据时，先回来对这张表：字段名与 bank 表对齐是「不为板块写分支」的前提。


────────────────────────────────────────
六、口径规矩（不许违反）
────────────────────────────────────────
- 比例分母一律是总股本：A+H 公司名册上两类股份混排，按 A 股基数重算会得出荒谬值
- 环形图是年报口径（一致行动人归并、铺满 100%），页头那行报告期末数与「股东明细」弹框里的
  增减是接口口径快照 —— 页面必须写明，两处不要相互对齐着读
- 「香港中央结算（代理人）有限公司」是名义持有人，穿透不了；
  「港股股东A／B」原样保留，不猜名字
- 纯 H 股公司接口不返回前十名股东：名单里保留并置灰，页面写明「不是取数遗漏」
- 手工层公司（百度按 20-F beneficial ownership、巴比按年报名册）要把口径说明原样印出
- 历年股本与分红逐年取自年报，不用接口的 total_share（那是当前值回填到每一年）；
  分红与接口那份取并集时，重叠年份以年报口径为准
- 不许手填、不许插值：年报与接口都没有的年份直接不画，缺口只记在数据层的
  `_meta` / `history_gaps` 里，不在页面上成段解释
- **页面上不留成段的口径说明**：底部「口径与接口限制」那一节已撤（逐家读各自的口径太累，
  按板块统一过一版也一样长）。口径与出处只由每张卡片右上角那枚来源标签承担（见第二节）；
  分红图连「展开详细口径」都不挂，要细查就去数据层看 `_meta`

七、多地上市：分市场的 top 持股披露（待做）
────────────────────────────────────────
目的：看清每个市场上到底有多少流通股、被谁拿着 —— 现在只有一张「占总股本」的环形图，
A+H 公司的 H 股筹码被摊进总股本里，分市场的集中度看不出来。

- A+H 公司在股东结构环形图上给三张（按钮切口径，与现有 ring_alt 那套按钮同一排）：
  1) A 股 top —— 分母为 A 股股本，名册取 A 股年报「前十名股东」／「前十名无限售条件股东」
  2) H 股 top —— 分母为 H 股股本，名册取年报披露的 H 股主要股东（≥5% 权益披露）
  3) 穿透后的真实持股 —— 把「香港中央结算（代理人）有限公司」这类名义持有人按年报／
     权益披露能穿透的部分拆出来，分母回到总股本
- 每张图的标题与说明必须写明：分母是哪一段股本、名册来自哪份年报的哪一章、
  披露门槛是多少（H 股 5% 权益披露与 A 股前十名不是同一口径，不许拼成一张图读）
- 穿透那张只画年报／权益披露里确有出处的部分，穿不透的余额留成一块
  「代理人名下未穿透」，不猜、不按比例摊
- 只 A 股或只 H 股的公司照旧一张图，不造第二张
- 三地（含美股 ADS，如百度）先只做 A/H 两段 + 穿透，ADS 那段等 20-F 口径确认后再说

八、分组（factions）口径整改（待做）
────────────────────────────────────────
现状问题：银行那 45 份分组表里，占大头的是「内资法人 42 / 国有股东 36 / 境外·H 股 36 /
保险资金 26」这种**按股东性质归的堆**，不是一致行动关系 —— 外圈看着像派系，其实是分类。

- 分组只留**一致行动人／关联方**（年报原文认定的：控股股东及其一致行动人、
  同一实控人下的多个账户、同一法人的两个席位）；认定不了的股东各自成组，不硬归堆
- 删掉按性质分的组：**内资法人**、**国有股东**、境外/H 股这类不再作为分组
- 新增一类 **ETF / 指数基金**（宽基 ETF、行业 ETF、联接基金）—— 它是被动筹码，
  与主动机构、产业资本的行为完全不同，值得单独一块
- 国有属性改成**标识**而不是分组：在环形图标注与「股东明细」弹框里给股东打「国有」标记
  （央企 / 地方国资 / 国有金融机构，来源写清是年报原文还是股东工商属性），
  同一个股东可以既是「国有」又落在某个一致行动人组里
- 图下说明相应改写：不再需要「同类归并不是一致行动人」那句免责，
  因为外圈只剩一致行动人 + ETF；标识用图例说明
